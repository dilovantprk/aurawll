Proje Özeti & Çözüm

Aura, bireylerin otonom sinir sistemi durumlarını (Ventral, Sempatik, Dorsal) izlemelerine ve bu durumları bilimsel nefes protokolleri ile regüle etmelerine imkan tanıyan modern bir bütünsel sağlık uygulamasıdır.

Geleneksel wellness uygulamalarının aksine Aura, kullanıcının otonom durumunu tespit etmek için interaktif bir Sematik Haritalama (Somatic Mapping) ve Affect Grid (Uyarılma-Valans Matrisi) kullanır. Ardından, saptanan duruma özel ses frekansları sentezleyen ve özel bir solunum rehberliği sunan akıllı bir yönlendirme motorunu devreye sokar.

Öne Çıkan Mühendislik Başarıları

İnteraktif Sematik Harita

Kullanıcıların bedensel hislerini (rhizome chips) seçerek nöral kümelenme algoritmaları üzerinden otonom durum tahmini yapabilmesini sağlayan dinamik girdi sistemi.

Biyosensör Web Audio

Web Audio API ile tarayıcı üzerinde gerçek zamanlı Pembe, Kahverengi ve Beyaz gürültü sentezleme, binaural vuruş (binaural beats) ve otonom duruma göre rezonans frekans modülasyonu.

Bicycle Day (LSD Mode)

WebGL gölgelendiricileri (custom fragment shaders) ile tasarlanmış, derin odaklanma ve mola süreçlerine senkronize çalışan gözü yormayan premium görsel terapi simülasyonu.

Temiz Kod ve 3 Katmanlı Mimari

Uygulamanın sürdürülebilir ve hatasız kalması için projenin tamamında katı kurallara sahip bağımsız bir 3 katmanlı yazılım mimarisi uygulanmıştır:

1. Core (Saf Mantık & State)
DOM manipülasyonu veya UI çağrılarından izole edilmiş, saf hesaplama motorları (vagal-engine), yerel veri durumları ve evrensel sabitler.
2. Services (Dış Entegrasyonlar)
Firebase veritabanı iletişimi, Web Audio API ses motorları (SensoryEngine) ve tarayıcı API entegrasyonları.
3. Components (UI & DOM orchestrator)
Dashboard, check-in akışları, nefes egzersizleri gibi görünüm bileşenleri. Bu katman sadece Core ve Services'ı ithal ederek görünümü yönetir.

Prosedüral Ses Sentezleme Sırları

Uygulama, statik mp3 dosyaları indirmek yerine sesi tarayıcı üzerinde sıfır gecikmeyle üretir. Aşağıda yer alan Web Audio API tabanlı pink noise üretici fonksiyonu bu yaklaşımın bir örneğidir:

// 2 saniyelik Pembe Gürültü Sentezleyici
const bufferSize = 2 * audioCtx.sampleRate;
const pinkBuffer = audioCtx.createBuffer(1, bufferSize, audioCtx.sampleRate);
const pinkData = pinkBuffer.getChannelData(0);
let b0 = 0, b1 = 0, b2 = 0, b3 = 0, b4 = 0, b5 = 0, b6 = 0;
for (let i = 0; i < bufferSize; i++) {
  let white = Math.random() * 2 - 1;
  b0 = 0.99886 * b0 + white * 0.0555179;
  b1 = 0.99332 * b1 + white * 0.0750759;
  b2 = 0.96900 * b2 + white * 0.1538520;
  b3 = 0.86650 * b3 + white * 0.3104856;
  b4 = 0.55000 * b4 + white * 0.5329522;
  b5 = -0.7616 * b5 - white * 0.0168980;
  pinkData[i] = b0 + b1 + b2 + b3 + b4 + b5 + b6 + white * 0.5362;
  pinkData[i] *= 0.11; // Genlik ölçekleme
  b6 = white * 0.115926;
}

Filtre katsayıları kullanılarak pembe gürültünün oktav başına -3dB zayıflama karakteristiği tam hassasiyetle simüle edilmiştir.
